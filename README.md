My website is a dual page website that works as a products and cart page, you can add items to the cart and fully interact with them, add more, remove it subtract it from btoh the products page and the cart. The nav bar connects the 2 pages asnd shows the amount of items in your cart. The footer does a similar thing, it has connecting links but it doesn't have the amount of items in your cart. The pages are easy to navigate, easy to understand and use. All of the items show the price on the products page with a fully functioning Add to Cart button. The button is slightly bolded to pop a little bit to catch a customers attention, all of the products are names after the website. The data is saved and works well with the website, it uses javascript to run all of the functions. The cart data gets saved for every change, gets restored when loaded and does not reset when refreshed. The cart page makes it easy to understasnd how it works. You can add each item to the cart, adjust the quantity as needed. It is a live server using the GitHub provided Pages.
